# 📝 To-Do App

A simple and responsive To-Do List application built with HTML, CSS, and JavaScript. This project helps users organize daily tasks efficiently through a clean and intuitive interface.

## 🚀 Live Demo

🌐 Live Website: https://sharjeel-akhter.github.io/To_Do_App/

## 📌 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clean and user-friendly interface
- Tasks remain saved after page refresh or browser restart

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🎯 How It Works

1. Enter a task in the input field.
2. Click the **Add** button.
3. The task appears in the task list.
4. Mark tasks as completed when finished.
5. Remove tasks that are no longer needed.

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/sharjeel-Akhter/To_Do_App.git
```

Navigate to the project folder:

```bash
cd To_Do_App
```

Open `index.html` in your browser.
